# Simple Interest Calculator

## Introduction
This project is a simple interest calculator that calculates the interest earned on a principal amount over a specified period at a given rate of interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal = Initial amount of money
- Rate = Annual interest rate
- Time = Time period in years

## Example

Principal = 10000

Rate = 5%

Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

**Result = 1000**

## Technologies Used
- Python

## Features
- Calculates simple interest.
- Accepts principal, rate and time.
- Displays the calculated interest.

## Conclusion
This project demonstrates the basic implementation of a mathematical formula using programming concepts.
